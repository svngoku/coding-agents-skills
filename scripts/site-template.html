Install and update the skills

The open agent skills CLI installs them into OpenCode, Claude Code, Codex, Cursor and 75 more agents. Requires Node.js 22.20 or later. Swap ddd for any skill name.

CLI documentation

One skill

npx skills add {{REPO_SLUG}} --skill ddd -a claude-code

Every skill

npx skills add {{REPO_SLUG}} --skill '*' -a claude-code

Update all

npx skills update

Update one

npx skills update ddd

Omit --skill to choose interactively, or add -g to install for every project. Updates re-read the lock file for their scope; pass -g or -p to update to target one scope.
